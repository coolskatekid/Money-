💰 Money Making Bot — CoolSkateKid

A free-first marketing assistant project designed to help promote CoolSkateKid artwork and attract genuine visitors to my Etsy shop.

🎨 About

CoolSkateKid creates colourful, playful alternative artwork inspired by cats, skateboarding, music, punk, emo, goth, rock and comic art.

Etsy shop: https://coolskatekidartwork.etsy.com

Art portfolio: https://coolskatekid.artlope.com/

Printify shop: https://coolskatekid-artwork.printify.me/

🚀 Project goals

- Generate promotional captions for real artwork.
- Suggest relevant hashtags and keywords.
- Prepare content for Pinterest, Instagram, TikTok, Facebook and YouTube Shorts.
- Save and export promotional drafts.
- Explore creating short videos from artwork.
- Prioritise free tools and legitimate promotion.
- Protect private credentials and artwork files.

✅ Current status

Features must be tested before being described as working.

The intended starter features are caption templates, local draft storage, caption downloads and backup exports.

Automatic social posting, AI API integration, video creation and scheduled publishing require separate implementation and testing.

🔒 Security

- Never commit API keys, passwords or private tokens.
- Store any future server-side API keys in the hosting provider's environment variables.
- Do not send promotional messages automatically without permission.
- Back up saved drafts before making major changes.

🛠️ Development

The project may contain separate website and Python components. Follow the instructions in each component's folder once its files and dependencies have been verified.

Test changes before relying on them. Do not claim that a feature works until it has been run successfully.

🎯 Main objective

Help more people discover genuine CoolSkateKid artwork through useful, honest and low-cost promotion, with the aim of increasing Etsy visits and sales.
